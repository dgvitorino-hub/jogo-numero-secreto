# Jogo do Número Secreto 🎲

Projeto prático do curso de Lógica de programação com JavaScript da Alura.

> O layout (HTML e CSS) foi fornecido pelo curso. 
> A lógica do jogo em JavaScript (`app.js`) foi desenvolvida por mim durante as aulas.

🔗 **Jogue aqui:** (https://dgvitorino-hub.github.io/jogo-numero-secreto/)

## Como funciona
O computador sorteia um número entre 1 e 100 e o jogador tenta adivinhar. 
A cada palpite, o jogo diz se o número secreto é maior ou menor e, 
ao acertar, mostra em quantas tentativas o jogador conseguiu.

## O que pratiquei no JavaScript
- Variáveis e template strings
- Condicionais (if/else)
- Laço de repetição (while)
- Geração de número aleatório (Math.random)
- Interação com o usuário (alert e prompt)
